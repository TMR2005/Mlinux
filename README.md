# MLinux MVP – Machine-Learning Optimized Linux Environment (WSL2 Prototype)

This is an MVP of MLinux, a Linux environment tuned for machine learning workloads.
It runs on Ubuntu under WSL2 with NVIDIA GPU passthrough and demonstrates:

- CUDA-enabled PyTorch for GPU training
- A custom system daemon that profiles CPU/GPU usage
- Basic OS tuning for ML workloads
